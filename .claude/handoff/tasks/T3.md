# T3 根因确认 + 修复①：目录页条目污染章节路径

## 背景
T2 抽检（`eval/audits/ocr_sampling/`）结论：10 份扫描文档 OCR 正文全部不达标。三类根因：
- A. 主 OCR（PaddleOCR 3.7.0 版面优先流水线，`parser_name=paddleocr-text`）整行丢失；疑似版面检测漏框导致框外行被丢弃。独立 OCR（RapidOCR+PP-OCRv6，`data/model_runtime/independent_ocr/runs/ocrv6-ef06411e1606ba35/pages/<sha>/pNNNN.json`，逐行 text+bbox）在 11 处已知丢失中找回 10 处。
- B. **目录页条目被当作章节标题**进入 `section_path`（例如 GB50268 正文块面包屑 `9 管道功能性试验 > 4.3 …`，GB50014 `8.11 Odor control > 2.0.26 …`）。Codex 判定 heading wrong 146/201。
- C. OCR 文档行序打乱、半句切块、碎片块（fragment 119/201）。

本卡做两件事：**(1) 只读确认根因 A 的机制**（为 T4 提供依据，不修 A）；**(2) 修复根因 B**。根因 C 留给后续卡。

## 范围
### 1. 根因 A 只读诊断（不改代码）
取 2 个页面：GB50014 `c3c3df5ae9ca…` 物理页 56、重庆导则 `4336797dedd1…` 物理页 25。对每页：
- 列出主 OCR 页中间结果（`data/canonical/pages/<sha>/<profile>/NNNN.json`，当前语料对应 profile 自行确认）的 layout boxes / regions / elements 与其文本；
- 列出 PP-OCRv6 同页逐行结果；
- 对 PP-OCRv6 有、主 OCR 无的每一行，判断其 bbox 是否落在任何主流程 layout box / region 内，并给出主流程丢弃它的代码路径（文件:行号）。
- 结论写入 `eval/audits/ocr_fix/T3_rootcause_A.md`：丢失是"版面漏框"、"识别失败"、"组装时丢弃"还是其他；附数字（每页丢失行数/原因分布）。只陈述证据，不提出大改方案以外的结论。

### 2. 修复根因 B：目录条目不得进入章节路径
- 找到 `section_path` / heading 栈的构建位置（`src/application/canonical_assembly.py` 或相关模块），说明目录条目是如何成为 heading 的。
- 实现目录页/目录条目识别（例如：引导点/省略号后接页码 `……（48）`、`…… 12`；连续多行"编号+标题+页码"模式；英文 Contents）。识别出的目录内容：
  - 不得推入 heading 栈、不得出现在任何正文 chunk 的 `section_path`；
  - 目录文本本身仍保留为元素（可定位），可标记 `role=toc`；处理/质量状态如实记录，不删除内容。
- 必须对**全部 23 份文档**生效且不回归：原生文档的 section_path 不应变差。
- 不改 ID 计算规则；若 element/chunk ID 因 section_path 变化而变化，属预期，需在报告中说明影响范围（受影响 chunk 数）。

### 3. 验证（以原图为准）
- 单元测试：目录模式识别（中/英、引导点变体、页码括号）、目录条目不进入 heading 栈、正常正文编号标题（如 `4.3.10 沟槽支撑应符合以下规定：`）不被误判为目录。
- 离线重算（不 ingest、不 publish）：用当前语料输入在本地重算 Canonical + chunks（可复用 `src/evaluation/ocr_sampling.py` 的重算路径或 `assemble` 的候选模式，产物写到候选/临时目录，不覆盖正式产物），输出：
  - 23 份文档各自 section_path 中仍含目录特征（引导点/页码）的 chunk 数：修复前 vs 修复后；
  - 对 T1 的 201 个样本位置（按 document + physical_page + bbox 重叠匹配新 chunk），新 `heading_path_text`；列出修复前 wrong → 修复后的变化统计。
- **原图对照**：在报告中给出至少 5 个样本的 修复前面包屑 / 修复后面包屑 / 原图中实际所属章节（查看 `crops/*__page.png` 或渲染原页）。GB50268 与 GB50014 至少各 2 个。
- 完整 pytest。
