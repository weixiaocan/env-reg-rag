# T2 OCR 样本独立判定（Codex 侧）

## 背景
T1 已产出 `eval/audits/ocr_sampling/sample_sheet.jsonl`（201 样本，10 份扫描文档）和本地截图 `crops/`（每样本每页：`context` 上下文图 + `page_thumbnail` 红框整页图）。判定标准固定在 `eval/audits/ocr_sampling/README.md`。

T2 是**双盲**：Codex 与 Claude 各自独立判定同一批样本，之后再合并比较。Claude 的判定在你完成之前不会放入仓库；**不得寻找、读取或推测 Claude 的判定**，也不得读取 `eval/audits/ocr_sampling/judgments_claude.jsonl`（如果出现）。

## 范围
1. 对全部 201 个样本逐条判定。每条必须**实际查看**该样本所有页的 `context` 图；判 `heading_path` 时查看 `page_thumbnail`。不得仅凭文本规则、OCR 置信度或其他引擎输出下结论。
2. 可以把 `data/model_runtime/independent_ocr/` 的独立 PP-OCRv6 结果作为**辅助提示**（例如定位疑似差异），但最终判定以你对原图的视觉核对为准；用到时在 `notes` 里写明。
3. 输出 `eval/audits/ocr_sampling/judgments_codex.jsonl`，每行：
   ```json
   {"sample_id": "...", "judge": "codex", "model": "<实际模型名>",
    "text_fidelity": "exact|minor|error|unjudgeable",
    "error_types": ["char|number_unit_clause|truncation_or_missing|extra_or_order", ...],
    "heading_path": "correct|wrong|not_applicable",
    "standalone_usable": "yes|fragment",
    "evidence": "差异原文对照：OCR『…』 vs 原图『…』（error/minor 必填，exact 可空）",
    "unjudgeable_reason": null,
    "images_viewed": ["<相对路径>", ...],
    "notes": ""}
   ```
   行按 `sample_id` 排序；201 行，一个不少。
4. 写一个轻量校验（可放 `src/evaluation/ocr_sampling.py` 或新模块，配单测）：判定文件 schema 合法、sample_id 集合与工作表完全一致、`error` 必有 `evidence` 与至少一个 `error_types`、`images_viewed` 覆盖该样本所有 context 图。
5. **只**输出 Codex 侧判定与各文档的 Codex 侧统计（`judgments_codex_summary.json`：每文档可判定数、error 数与比例、Wilson 95% 区间、heading wrong 比例、fragment 比例）。**不要**做合并、不要下文档准入结论。
6. 提交一次（英文提交信息，末尾 `Co-Authored-By: Codex <noreply@openai.com>`）。

## 禁止
- 不改工作表、截图、抽样或准入逻辑；不 assemble/ingest/publish；不改 `data/registry/`。
- 不调用外部 LLM API（你自身作为执行模型查看图片不算）；不下载模型。
- 不读取 Claude 的判定。

## 验收标准
- 201 行判定，校验通过；单测与完整 pytest 结果原文写入报告。
- 报告给出 Codex 侧各文档统计表，以及 3–5 个代表性 error 的原文对照。
