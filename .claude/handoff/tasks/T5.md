# T5 修复③：用独立 PP-OCRv6 结果补全/纠正主 OCR 的真实缺失

## 背景
T3/T4 已修复目录污染与阅读顺序。剩余问题是主引擎（PaddleOCR 3.7.0 结构化流水线）**真实识别缺失**：GB50014 p56 有 5 条有效原文行不在 `parsing_res_list` 中（均在已有 layout region 内）；还有字符错误（`载`→`奉`、`进行`→`进`）和款号缺失（`4 中继间…` 丢 `4`）。独立 OCR run `data/model_runtime/independent_ocr/runs/ocrv6-ef06411e1606ba35/`（RapidOCR + PP-OCRv6，按 PDF sha256 + 物理页，逐行 `text/bbox/score`，覆盖全部 10 份扫描文档）在审核者探测的 11 处已知缺失中找回 10 处（`eval/audits/ocr_fix/probe_independent_ocr_recovery.py`）。

目标：在保留主引擎版面结构（region/表格/公式/图片划分）的前提下，让 OCR 页的**正文文字**尽可能与原图一致，并保留完整来源记录。

## 范围
### 1. 对齐与统计（先测量，再决定规则）
对 10 份扫描文档的全部 `full_ocr`/`hybrid` 页，把 PP-OCRv6 行与主 OCR 元素对齐（几何 + 文本相似度；先确认 run 的 `file_sha256` 与当前源文件一致、页坐标换算正确），每行归类：
- `same`（规范化后相同）、`differ`（对齐但文字不同）、`pp_only`（主 OCR 无对应）、`primary_only`（PP-OCRv6 无对应）。
- `pp_only` 再分：落在正文 text region 内 / 落在表格、公式、图片 region 内 / 不在任何 region 内；以及疑似水印噪声（例如单字、与已知水印文字"住房城乡建设部""浏览专用""信息公开"等匹配、低 score）。
输出 `eval/audits/ocr_fix/T5_alignment_stats.json`（按文档汇总）。

### 2. 校准集（与测试集分离）
- 从上述 `differ` 与 `pp_only` 中，**排除 T1 的 201 个样本所在页**，按文档分层随机抽约 60 行（固定种子），对照原图（渲染该行 bbox 上下文）逐条判定：主 OCR 对 / PP-OCRv6 对 / 都错 / 是水印噪声。
- 结果写 `eval/audits/ocr_fix/T5_calibration.jsonl`（每条带"OCR『…』vs PP『…』vs 原图『…』"具体文字，不得模板化），并汇总胜率。
- 根据校准结果确定融合规则（例如：`pp_only` 且在 text region 内且非噪声 → 插入；`differ` 时以 PP-OCRv6 为准或按 score/长度条件选择）。规则必须由校准数据支撑，写明数据依据。

### 3. 实现融合
- 位置：在 page-intermediate → Canonical 的文本元素生成环节（或独立的、在统一入口内被调用的融合步骤）实现；**不得新增绕过统一入口的第二条发布路径**。PP-OCRv6 run 作为显式输入（记录 run_id 与 run_manifest 哈希），缺失时硬失败或明确降级记录，不得静默回退。
- 只作用于 OCR 路由页的**正文 text 元素**；表格/公式/图片区域内文字不改（另有 D3 规则）。
- 每个被插入或替换的元素记录 provenance：引擎、run_id、原主 OCR 文本（若替换）、对齐分数、融合规则版本。quality_status 维持 `needs_review`（准入由后续抽检决定）。
- 阅读顺序与 section 归属沿用 T3/T4 修复后的逻辑；插入行必须按 y 顺序就位。

### 4. 验证（原图为准）
- 离线内存重算（同 T3/T4 方式），不写正式产物。
- 对审核者已知的缺失逐个给出修复后文本：GB50014 p56 第3款/第5款/`~`、`ocr-c3c3df5ae9ca-006`（载体表面…）、`ocr-fd10712cb0f7-010`（第4款编号）、`ocr-fd10712cb0f7-012`（合格后进行、款号）、`ocr-60bfe78380e9-013`（3.1.4–3.1.6）、`ocr-f28bb600c899-002`（红章区"大雨、暴雨、大暴雨、特大暴雨共7个等级"）。
- 201 样本位置：重新匹配新 chunk，给出 body 变化统计（不判定合格，判定留 T6）。
- 原图对照 ≥6 个修复前/后实例；单列至少 2 个"融合引入了新错误或噪声"的检查结果（如有）。
- 单元测试：对齐归类、噪声过滤、插入顺序、provenance 记录、run 缺失时的行为。完整 pytest。
