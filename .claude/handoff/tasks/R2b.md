# R2b 伪原生扫描页改路由 + 条文连续性口径修正

## 背景（Claude 审核 R2 发现）
1. **伪原生扫描件**：`城市排水工程规划规范.pdf`（59/60 页）与 `T_CECS_758-2020城镇排水管道混接调查及治理技术规程.pdf`（75/75 页）每页是一整张扫描图（覆盖 >80% 页面）+ 第三方嵌入的低质量 OCR 文字层，却被路由为 `native` 并直接采信文字层。例：T/CECS 758 p67 原图"上下游水质**浓度**降低"，文字层为"水质**放**度降低"（金标准 TXT-07 失败根因；TXT-06 同文档）。其余 11 份原生文档 0 页命中该特征。
2. **条文连续性口径**：R2 报 missing 269 / duplicate 410，主要由 (a) 条文说明重复使用条号、(b) 公式编号被误解析为条号（GB50014 出现 `4.1.154` 之类，撑出 4.1.15–4.1.153 的假缺号）造成。按"正文/条文说明分开"重算后，正文缺号多为 0–9（多普勒 9、武汉 9、城市排水规划 13、城镇内涝 2、GB/T 47884 2、福建 1）。

## 范围
1. **路由规则（通用，不针对文件名）**：页面上单张图像覆盖 ≥80% 页面面积且存在文字层 → 判为 `scanned_with_text_layer`，按 OCR 页处理：嵌入文字层作为三源投票中的 `primary` 来源，另跑 pp_raw 与 pp_clean。规则写进路由/页面准备代码并加测试（反例：原生页内嵌小图、页面背景图但文字为矢量）。
2. 对命中页运行 PP-OCRv6 无预处理与预处理两种 run（本地已有模型；可续跑；用 `PYTHONPATH=<repo>`），记录 run id。
3. **条文连续性统计修正**：正文与条文说明分开命名空间；公式编号（`(4.1.15-4)`、`式 x.x.x-n`）、表号、图号不得作为条号；输出每份文档正文缺号/重号清单，并对每个缺号给出 页码 + 该页 PP 三源是否出现该条号 的证据字段。
4. 重跑 `run_rollout.py`（23 份全量），更新 `rollout/metrics.json`、`exam.json`、`review_samples/`；报告前/后：金标准、两份伪原生文档的 A2 指标、正文缺号清单。
5. 完整 pytest。
