# R1 中间层 v3：实现 + GB 55027 试点

## 必读
`.claude/handoff/MIDDLE_LAYER_V3_SPEC.md`（方案，负责人已批准）、`AGENTS.md`、`.claude/handoff/PROTOCOL.md`。

## 范围
1. 按方案第 3 节实现中间层 v3（新模块，例如 `src/ingestion/block_assembly.py` + `src/ingestion/page_furniture.py` + 水印/页码规则配置文件），通过 `assemble_corpus_v2.py --middle-layer v3` 接入；legacy 保持默认，**本卡不删除旧代码**。
2. 复用：`independent_ocr_fusion.py`（规则 t5-calibrated-v1）、`column_detection.py`（T4 修正版）、表格/公式/图片既有组装、`compute_ids`、`validate_document`、`evidence_policy`。不要复制粘贴旧行级推断逻辑。
3. **试点只跑 GB 55027-2022**（sha `60bfe78380e9533e32ef659b054daf9fa7f072557824b7ae759b51371f1ca41f`，20 页）：离线内存组装 + `chunk_document`，不写正式产物、不 ingest。
4. 输出试点产物到 `eval/audits/middle_layer_v3/pilot_gb55027/`：
   - `chunks.jsonl`：每个 chunk 的 chunk_id、section_path 文本、body、element 类型、页码、bbox；
   - `page_review.md`：逐页列出该页所有 chunk 的 section_path + body（供审核者对照原图），以及被标为页面家具/目录的文本及命中规则；
   - `metrics.json`：方案第 6 节 A2 各项指标（该文档）+ legacy 同文档对比。
5. 单元测试：标签映射、页面家具（含反例：正文里的合法数字、含"住房城乡建设部"的正文句子）、条文切分（含"以数字开头的续行"反例）、标题层级（text 块不得成标题、Ⅰ/Ⅱ 小节、编号前缀一致性）、无 region 兜底。完整 pytest 全绿。
