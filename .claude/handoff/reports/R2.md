## 结论

R2 的离线执行与验收材料已完成：复用审核者已生成的预处理 OCR run，对 23 份文档完成内存 v3 组装、`validate_document`、`chunk_document` 和 legacy 同口径对照；Canonical 校验 23/23，通过完整 pytest（1209 passed）。未 ingest、未 publish、未改 `data/registry/corpus-current.json`，也未写入 Canonical 候选目录。

内容质量门槛尚未全部通过，不能把本报告表述为 R2/R3 验收 PASS：金标准原始结果为条文文本 16/20、结构 15/19、表格 10/10；其中 3 个条文失败满足“两套 OCR 均无完整真值”的豁免证据，另 1 个 `TXT-07` 不满足豁免条件。条文连续性仍有大量待逐例举证记录，详见 `metrics.json`。

## 做了什么

1. 核对但未重跑审核者 OCR run `ocrv6-fe621f3631762fd6`：`selected_page_count=602`、`completed_page_count=602`、推导失败页 0；预处理参数为 `light-gray-red-v2-preserve-dark-edge`、`gray_threshold=120`、`red_delta=60`、`red_min=140`。
2. 增加 `run_rollout.py`，只在内存中对 23 份文档分别组装 v3 与 legacy，生成全量 chunk、逐文档 A2 指标、三源文字统计、固定种子审核样本和失败账本。
3. 补齐原生页路径的伪粗体去重：只删除文字相同且 bbox 双向覆盖率至少 0.8 的重叠行；相同文字位于不同位置时保留。
4. 修正原生文字层常见的条款前缀结构解析：`1. o. 1`、`7. 1. 1` 等只在结构标签中规范为 `1.0.1`、`7.1.1`，正文原始文字不伪改。
5. 两栏判定增加左右栏必须存在至少两组垂直重叠块的条件，避免单栏页的错位短标题被误判为双栏。
6. 对中文序号项（如 `（九）`）建立 section 锚点；句末完整陈述不再标成 heading，仍保留其结构标签。
7. 水印整行命中增加右侧正式落款反例，避免把通知落款中的“住房城乡建设部”当成水印。
8. 修正 A2 统计口径：目录页码不计入正文家具；结构化表格中的 `>` 不计为正文面包屑；短正文比例只统计含 text 元素的 chunk。
