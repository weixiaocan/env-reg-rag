# 排水规范证据检索

本上下文描述面向排水工程人员的规范性文件检索与问答。系统的核心产物是可核验的规范依据，不替代专业人员作出法律解释或合规结论。

## Language

**规范性文件**:
本系统收录对象的统称，包括法规、强制性工程建设规范、国家标准、行业标准、地方标准、团体标准、政策文件和经批准的企业手册。
_Avoid_: 法规库（当语料并不全是法规时）、普通文档

**文档版本**:
一份规范性文件在特定发布、实施和效力状态下的独立版本。同一标准号的不同年份是不同文档版本。
_Avoid_: 文件、PDF

**原始文件资产**:
一组内容完全确定的原始字节，以 SHA-256 标识。同一内容即使使用不同文件名，也只登记为一个原始文件资产；它是文档版本的载体，不等同于文档版本本身。
_Avoid_: 用文件名判断重复、把同标准号的不同文件直接视为重复

**文档准入状态**:
文档版本获准进入哪一类使用范围的业务判断，包括待审核、仅限实验、可进入正式语料、隔离和撤回。它不表示文件是否解析成功。
_Avoid_: 处理状态、发布状态、有效性结论

**处理状态**:
一次解析或后续处理运行的结果，包括未处理、处理中、质量通过和处理失败。新工具或新配置产生新的处理运行，不覆盖既有运行。
_Avoid_: 文档准入状态、语料版本状态

**语料版本**:
一组固定文档版本及其指定处理产物构成的可复现集合。查询和评估必须能够指明所使用的具体语料版本。
_Avoid_: 当前数据库、全部文件

**语料版本状态**:
语料版本从草稿、已构建、已发布到已撤回的发布生命周期。只有满足准入规则且处理质量通过的文档版本才能进入可发布语料版本。
_Avoid_: 文档状态、索引是否存在

**权威来源**:
能够证明文档版本、发布机构和效力状态的官方发布页或企业受控文档系统记录。
_Avoid_: 下载网站、网盘来源

**适用性**:
某文档版本对指定地域、业务阶段、对象和时间点是否适用的属性集合。
_Avoid_: 权重、相关性

**条款**:
规范性文件中可独立定位和引用的最小规范单元，保留其章、节、条、款、项层级关系。
_Avoid_: 固定长度文本块、段落

**证据单元**:
带有稳定身份和原文定位的检索事实单元。质量通过的条款、款项、政策段落或完整表格可以支持回答主张；仅定位单元只能引导用户查看原文。
_Avoid_: 证据片段、固定长度文本块、知识

**可引用证据**:
文字或表格转写已经通过质量门控、可以直接支持回答主张的证据单元。
_Avoid_: 只要能检索到就视为可引用

**原文定位单元**:
自动转写尚不可靠、但文档和页码定位可信的可检索单元。它只能返回原文入口和质量提示，不能把转写内容当作确定答案。
_Avoid_: 无答案、可引用证据

**检索块**:
为提高召回而从一个或多个证据单元派生的搜索文本，可以附加标题路径、表头和父级语境，但不是最终引用事实。
_Avoid_: 证据单元、原文

**数值区间投影**:
从当前语料版本内已批准的表格证据派生、可重建的结构化检索数据，保存指标、单位、条件、上下界、类别和原表 evidence ID；用于确定性区间匹配，命中后仍回取并引用原表证据。
_Avoid_: 新事实源、第二套向量数据库、让大模型自由计算区间

**证据定位**:
证据单元回到规范性文件原文所需的文档版本、物理页、页面元素和坐标集合。
_Avoid_: 只有页码的字符串、模型生成的出处

**检索语境**:
附加在检索块中的标题路径、父条款或相邻说明，用来消除短条款和表格数值的歧义，不改变证据单元的原文边界。
_Avoid_: 父子上下文、聊天上下文

**回答主张**:
最终回答中需要被一个或多个证据片段直接支持的事实性陈述。
_Avoid_: 答案段落

**引用**:
回答主张与证据单元之间可机器校验、可由用户回查的关联。
_Avoid_: 模型生成的参考文献字符串

**证据不足**:
现有可访问语料无法为问题形成足够证据的状态，包括未收录、版本不明、适用性冲突和检索置信不足。
_Avoid_: 模型不会、查询失败

**拒答**:
系统在证据不足或问题超出范围时返回的受控产品结果，并说明缺少什么以及用户下一步可以怎么做。
_Avoid_: 报错、无结果

**查询请求**:
一次明确的问题提交，包含问题文本、显式会话条件、语料版本和调用方身份；它不依赖界面或连接中的隐式状态。
_Avoid_: prompt、聊天消息

**已解析适用范围**:
系统从查询请求中确认的地域、时间、对象、文种和统计口径等条件，以及尚缺失的决定性条件。
_Avoid_: metadata filter、模型理解

**缺失条件**:
会改变规范依据或答案结论、但当前查询请求没有给出的条件，例如降雨统计时段。缺失条件必须结构化返回，不能由模型静默假设。
_Avoid_: 参数错误、追问文本

**受控追问上下文**:
查询结果显式返回、并由下一次查询请求原样携带的最小问题锚点和适用范围；它只支持补充或修改决定性条件，不是服务端隐式聊天记忆。
_Avoid_: 完整聊天历史、隐藏会话状态、通用长期记忆

**待补充问题**:
因缺少决定性条件而尚未执行回答的原始问题，是下一轮条件补充所依附的问题锚点。
_Avoid_: 上一条消息、任意聊天上下文

**证据包**:
一次查询中经过语料版本、适用性和使用策略检查后，允许后续回答流程使用的证据集合。检索候选只有进入证据包后，才可能支持回答主张或原文定位。
_Avoid_: top-k、上下文窗口、LangChain Document 列表

**查询结果**:
查询核心对一次请求的最终领域结果，具有已回答、需要澄清、仅搜索、来源冲突或拒答之一的明确状态，并携带该状态允许出现的答案、证据和提示。
_Avoid_: 大模型回复、HTTP response


**来源差异**:
多份可引用证据对同一事项存在不同表述或要求，但差异可能由地域、时间、对象或文件层级不同造成，尚不能认定为冲突。
_Avoid_: 来源冲突、错误答案

**来源冲突**:
在已解析适用范围内，至少两个不同文档版本的可引用证据给出不能同时成立的要求；查询结果分别展示这些要求和证据，不替用户裁决。
_Avoid_: 只要两份文档内容不同就判冲突、自动选择更严格要求
