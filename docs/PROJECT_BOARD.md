# 环保法规规范证据助手——项目任务看板

## 1. 看板怎么读

- `[x]`：已有可检查产物并通过当前阶段验收。
- `[ ]`：尚未完成。
- `▶ 当前`：下一项正在推进的阶段。
- 本看板只展示中等粒度任务。测试、表结构、哈希算法等实现细节归入对应阶段的验收证据，不单独冒充项目进度。

## 2. 项目全景

**最终目标**：完成一个可开源、可演示、可评估的环保法规规范 RAG 应用。它能持续扩展资料库、连续追问，返回带文档、条款和页码定位的证据，并能被网页、API 和后续 Agent/MCP 复用。

**当前所在位置**：M6 已按“可演示、可复现、可进入开源准备的企业式单机 POC”范围通过；现在进入 P7，处理开源与面试交付。

  ↓

## 5. 看板维护规则

- 每次开始新阶段前，先说明它在本看板中的位置和目的。
- 只有存在可复核产物并通过阶段门槛，才能把任务改为 `[x]`。
- 细节任务不新增为顶层阶段；它们只能作为某个阶段的实现或验收证据。
- 范围发生变化时，先更新产品/技术规格，再同步本看板，不能只改代码。
- 每轮结束时只汇报：完成了哪个大阶段、产生了什么证据、下一步为什么做。
