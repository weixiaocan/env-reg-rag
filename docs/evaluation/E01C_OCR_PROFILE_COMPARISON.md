# E-01C OCR 轻重路径对照与候选路由

## 1. 这次实验回答什么

E-01B 证明 PP-StructureV3 可以接入，但完整表格管线在 CPU 上较重。本轮只回答两个更具体的问题：

1. 普通扫描正文关闭表格识别后，是否能保持相同文字质量并降低资源占用？
2. 含证据型表格的页面，表格重路径是否带来轻路径无法提供的有效结构？

对照固定 PaddlePaddle 3.3.1、PaddleOCR 3.7.0、PaddleX 3.7.2、PP-OCRv5 中文、CPU、200 DPI 和关闭 MKLDNN。两条路径唯一有意改变的变量是 `use_table_recognition`。

## 3. 观察与结论

### 3.1 普通条款页

M2-P035 的两条路径得到完全相同的正文、结构元素、质量状态和锚点结果。关闭表格识别没有明显缩短单页冷启动时间，但结束时 RSS 减少约 853 MB，峰值工作集减少约 649 MB。

结论：普通条款、目录和参考文献使用 `text_layout_light`。收益是减少常驻模型和内存，不宣称能显著降低单页延迟。

### 3.2 证据型表格页

M2-P001 原页包含降雨等级表。轻路径仍检测到 `table` 版面块，但该块内容为空，表内档位与数值没有进入规范正文；重路径生成独立表格对象，恢复 12 h/24 h 表头、降雨等级和主要数值。

重路径没有变快，却把结束时 RSS 提高约 1558 MB、峰值工作集提高约 2222 MB。这里的额外资源换来了真实能力：若没有重路径，系统无法可靠回答“20 mm 属于什么降雨等级”这一核心业务问题。

结论：`table`、`tables`、`clause_and_table` 和 `clause_and_tables` 使用 `table_structure_heavy`。表格锚点仍需要字段/数值级评价，不能用整段连续子串命中率代替。

### 3.3 公式和图示

关闭表格模型不能解决公式或流程图结构。当前策略让这些页面先走文字轻路径，以便获得可搜索的说明文字，同时强制专项复核：

- `formula`：`formula_structure`；
- `flowchart`、`clause_and_figure`：`visual_structure`。

在专项能力通过实验前，这些结构本身不能作为可发布证据。

### 3.4 表格字段/数值评价

10 个已人工批准的表格锚点已经机械拆分为字段/数值检查项，保存在 `m2-table-anchor-assertions-v1.json`。拆分只使用批准原文中已有片段，不增加新的业务事实。

检查器容忍空格、`～/~`、罗马数字字形和常见单位写法差异，但不会容忍关键字段错字。对现有重路径结果回算：

- M2-P001：2/2 检查项通过；
- M2-P006：1/1 检查项通过；
- M2-P036：9/10 检查项通过，仍准确暴露“管网竣工数据资料”被识别为“管网峻工数据资料”。

M2-P036 同页存在两张表，因此 TAB-10 使用“地块项目”选择目标表后再检查。这样不会让另一张市政道路表里的正确文字掩盖目标表错误。

## 4. 24 页候选路由

版本化计划保存在 `data/registry/m2-ocr-route-plan-v1.csv`：

- 11 页 `table_structure_heavy`；
- 13 页 `text_layout_light`；
- 其中 1 个公式页和 2 个图示页带强制专项复核原因；
- 全部状态为 `proposed_after_profile_comparison`，尚未改成最终批准。

最终批准仍需运行全部候选并结合文字锚点、表格字段/数值、特殊结构和失败原因逐页决定。

## 5. 工程决定

项目不采用“只要 PDF 没文字层就统一 OCR”的规则，而采用两层判断：

```text
文字层预检
  -> 页面内容类型
      -> 普通文字：text_layout_light
      -> 证据型表格：table_structure_heavy
      -> 公式/图示：text_layout_light + mandatory review
  -> 置信度、人工锚点和结构门控
      -> 通过 / 复核 / 隔离
```

该决定直接影响后续 Canonical Document：轻路径可以保留文字块；重路径必须额外保存表格 HTML、扁平文字、单元格结构和表格区域定位；公式/图示不可被伪装成普通文本证据。

## 6. 下一步

1. 按 v1 路由计划分别运行 13 页轻路径和 11 页重路径。
2. 汇总 24 页结果，与 14 页原生路径和 2 页空白页合并，形成40页逐页路由决定。
3. 对公式与图示失败页决定专项解析还是 `quarantine`。
