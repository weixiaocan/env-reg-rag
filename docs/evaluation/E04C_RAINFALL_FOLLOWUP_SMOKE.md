## 1. 验证场景

使用正式语料 `formal-corpus-v1`、Qdrant alias `corpus_current`、本地 BGE、数值区间投影和智谱 `glm-5.2`，验证真实用户问题能否完成“追问条件 → 补充条件 → 有引用回答”的完整链路。

## 2. 执行结果

第一轮输入“降水量为20毫米时属于什么等级？”，结果为 `needs_clarification`，缺失条件为 `statistical_period`，未调用回答模型。

第二轮只输入“12小时”，并显式带回第一轮的受控追问上下文。结果为 `answered`，已解析统计时段为 `12h`。模型回答：

回答引用 `GB/T 28592-2012` 第 4 物理页的“表1不同时段的降雨量等级划分表”，目标 evidence ID 为 `ev_18de8c71615152558e1368e48ee73d1d`。第二轮端到端耗时约 7.61 秒，结果通过。

机器可读执行记录保存在 `data/eval_results/m4-zhipu-rainfall-followup-v1.json`。记录不包含 API 密钥。
