# E-04B 数值区间表格检索评估

## 1. 评估目的

验证正式语料中的数值区间表格能否回答“一个具体数值落在哪个区间”这类问题。此前 dense、BM25 和 RRF 都无法让 AI-001、AI-002 的目标表格进入 Top-5，因为相似度检索不会执行 `20 ∈ [10.0, 24.9]` 这类确定性判断。

## 2. 实现边界

系统从已批准、允许引用且属于当前正式语料版本的表格证据中，派生可重建的数值区间投影。投影只保存指标、统计时段、类别、上下界、单位和 evidence ID；它不是新的事实源，也不替代 Qdrant。

查询时先解析问题中的指标、数值、单位和统计时段，执行确定性区间匹配，再按 evidence ID 从 Qdrant 回取原始表格检索块并提升到 EvidencePack 首位。其余候选仍由 Qdrant RRF 召回，最终回答只能引用原表 evidence ID。

## 3. 正式语料结果

| 用例 | 问题条件 | 期望类别 | 实际类别 | 原表排名 | 结果 |
|---|---|---:|---:|---:|---:|
| AI-001 | 24 小时、20 毫米 | 中雨 | 中雨 | 1 | 通过 |
| AI-002 | 12 小时、20 毫米 | 大雨 | 大雨 | 1 | 通过 |

结果为 **2/2 通过**。两题均回取 `GB/T 28592-2012` 第 4 物理页“表1不同时段的降雨量等级划分表”，证据 ID 为 `ev_18de8c71615152558e1368e48ee73d1d`。

机器可读结果保存在 `data/eval_results/m4-numeric-range-retrieval-v1.json`，其中记录了证据单元文件和正式语料 manifest 的 SHA-256。该评估只使用本地 BGE 与 Qdrant，没有调用付费回答模型。

## 4. 当前限制

首版只批准“降雨量 + 毫米 + 12h/24h + 等级区间”这一种表格模式。缺少统计时段时仍进入受控追问，不猜测列；未批准表格、非正式语料文档和其他单位不会进入投影。后续新增指标时，应先增加对应表格模式和边界测试，而不是让模型自由计算。
