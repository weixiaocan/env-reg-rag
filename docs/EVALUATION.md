这些数字不代表并发吞吐，也不能外推到其他硬件、模型或更大语料。

## 已知限制

- 固定测试集规模较小，检索指标是回归基线而不是行业准确率。
- 36 个模型请求中有 2 次遗漏补充信息，但正确证据均已召回；生成完整性仍受模型波动影响。
- OCR 重路径对复杂表格仍需质量门控，失败页面不会自动进入正式回答语料。
- 当前部署是单机 POC，尚未验证多用户并发、远程 MCP 认证、多副本高可用或异地灾备。
- 已记录 token 使用量，但未配置经过核实的实时费率，因此不报告成本金额。
